SKI RESORT TRACKER — LOGO FILES

Concept
A mountain ridge doubles as a tracking line. The mint point suggests a fresh observation within the mountain-conditions data. The restrained palette matches the existing dark interface.

Use
• ski-resort-tracker-logo-dark.svg/png: horizontal logo for dark/navy backgrounds. Transparent, with near-white lettering.
• ski-resort-tracker-logo-light.svg/png: horizontal logo for white/light backgrounds. Transparent, with navy lettering and higher-contrast symbol colors.
• ski-resort-tracker-mark.svg/png: standalone symbol, transparent, best on dark backgrounds.
• ski-resort-tracker-app-icon.svg/png: navy rounded-square app icon.
• favicon.svg / favicon.ico / favicon-16,32,48.png: browser tab assets.

Recommended minimums
Use the standalone app icon at 24px or larger when possible. The 16px favicon is supplied for browser compatibility. Use the full wordmark at 240px wide or larger. Leave at least one tracking-point diameter of clear space.

Palette
Navy #081019
Ice #9BC5DA
Snow #EDF4FB
Mint #65D8C6
Light-background symbol: #326981 / #087E70

Production notes
SVGs contain genuine editable vector paths/shapes. The Inter wordmark is outlined, so the font does not need to be installed. PNGs have transparent backgrounds except for the app-icon tile. Vector artwork is an original clean construction of the mountain-track concept; it is not a raster embedded in SVG. Image generation was used for early concept exploration. No changes were made to the live website.
